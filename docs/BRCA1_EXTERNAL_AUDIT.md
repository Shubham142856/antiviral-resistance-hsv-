# External assay analysis plan

Recorded before calculating any BRCA1 benchmark outcomes. This is a local analysis plan, without an independent registration timestamp. The prior HSV results were known. We selected the Findlay et al. BRCA1 saturation genome editing dataset for its independent experimental origin and author-defined phenotype classes.

- Use the normalized MaveDB score set `urn:mavedb:00000097-0-2`. Keep single missense SNVs classified functional or loss of function by the authors. Count each assayed nucleotide variant once. Retain multiple SNVs at the same protein position in the same fold. Exclude intermediate calls from the primary contrast.
- Use residue number as the sole model input. Reuse the HSV random forest and five-fold position-grouped split. For regional holdout split the sorted distinct observed positions into five consecutive groups differing in size by at most one site. This avoids empty blocks in the long unassayed interval between BRCA1 domains. This changes the definition of a block from the original HSV analysis.
- Primary contrast: grouped minus blocked pooled out-of-fold AUROC. Report a paired percentile interval with 2,000 position bootstrap draws and seed 42, conditional on fitted scores. Evidence for same-direction transfer requires a positive lower 95% bound. Report the result irrespective of direction.
- Report nearest-training-site gaps, evaluable fold counts, within-fold AUROCs, within- and between-fold pair concordance and the training-prevalence-only control. No hyperparameter or boundary tuning.
- Secondary biological question: within the same exon, do sequence-adjacent measured residues have more similar fractions of loss-of-function missense SNVs than expected from exon membership alone? Weight each adjacent pair equally and use only consecutive residue numbers. Test the mean absolute difference of the site-level fractions against 9,999 permutations of the fractions within exon (seed 42, lower tail, add-one p-value). Report the observed and mean null differences, pair and exon counts. Exclude sites with ambiguous exon membership. Site coverage and substitution composition can affect this comparison. Treat it as a descriptive assay-specific test. If exon annotation is unavailable, record that limitation.

The external endpoint measures cellular assay function. Neither patient outcomes nor antiviral resistance are endpoints of this replication.
